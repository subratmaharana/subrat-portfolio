## Run Locally

Clone the repository:

```bash
git clone https://github.com/subratmaharana/subrat-portfolio.git
Go to the project directory:
cd subrat-portfolio

Install dependencies:
npm install

Start the development server:
npm run dev

The application will run locally at:
http://localhost:5173
